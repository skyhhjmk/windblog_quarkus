# 分类与标签管理功能规格文档

## Why

当前 Flutter 管理后台缺少分类和标签管理功能，而文章编辑页面也无法选择分类和标签。这导致：

1. 用户无法通过后台管理文章分类结构
2. 文章无法关联到分类和标签
3. 博客的内容组织能力受限

## What Changes

- **新增分类管理页面**: 树形结构展示分类，支持增删改查
- **新增标签管理页面**: 列表展示标签，支持增删改查
- **增强文章编辑功能**: 在文章编辑对话框中添加分类选择和标签输入
- **新增 API 客户端方法**: 对接后端分类和标签接口
- **新增数据模型**: Category 和 Tag 相关的模型类
- **更新导航菜单**: 在 HomePage 导航栏添加分类和标签入口

## Impact

- 新增页面: `categories_page.dart`, `tags_page.dart`
- 修改页面: `posts_page.dart` (添加分类/标签选择)
- 修改文件: `admin_api_client.dart` (添加 API 方法)
- 修改文件: `models.dart` (添加模型类)
- 修改文件: `home_page.dart` (添加导航项)
- 修改文件: `zh.json`, `en.json` (添加国际化文本)

## ADDED Requirements

### Requirement: 分类管理功能

系统应提供完整的分类管理功能，支持无限层级结构。

#### Scenario: 查看分类列表

- **WHEN** 用户进入分类管理页面
- **THEN** 系统应以树形结构展示所有分类
- **AND** 显示分类的名称、slug、描述信息

#### Scenario: 创建分类

- **WHEN** 用户点击创建分类按钮
- **THEN** 系统显示创建对话框
- **AND** 用户可以输入 slug、名称(多语言)、描述(多语言)
- **AND** 用户可以选择父分类(可选)
- **AND** 保存后分类被创建

#### Scenario: 编辑分类

- **WHEN** 用户点击编辑按钮
- **THEN** 系统显示编辑对话框
- **AND** 用户可以修改分类信息
- **AND** 保存后分类信息更新

#### Scenario: 删除分类

- **WHEN** 用户点击删除按钮
- **THEN** 系统显示确认对话框
- **AND** 确认后分类被删除

### Requirement: 标签管理功能

系统应提供标签管理功能，支持标签的增删改查。

#### Scenario: 查看标签列表

- **WHEN** 用户进入标签管理页面
- **THEN** 系统以列表展示所有标签
- **AND** 显示标签的名称、slug、描述信息

#### Scenario: 创建标签

- **WHEN** 用户点击创建标签按钮
- **THEN** 系统显示创建对话框
- **AND** 用户可以输入 slug、名称(多语言)、描述(多语言)
- **AND** 保存后标签被创建

#### Scenario: 编辑标签

- **WHEN** 用户点击编辑按钮
- **THEN** 系统显示编辑对话框
- **AND** 用户可以修改标签信息
- **AND** 保存后标签信息更新

#### Scenario: 删除标签

- **WHEN** 用户点击删除按钮
- **THEN** 系统显示确认对话框
- **AND** 确认后标签被删除

### Requirement: 文章编辑增强

文章编辑功能应支持选择分类和添加标签。

#### Scenario: 选择分类

- **WHEN** 用户编辑文章时
- **THEN** 系统显示分类选择器
- **AND** 用户可以从树形结构中选择主分类
- **AND** 选择的分类 ID 随文章保存

#### Scenario: 添加标签

- **WHEN** 用户编辑文章时
- **THEN** 系统显示标签输入区域
- **AND** 用户可以输入标签名称(支持自动完成)
- **AND** 可以添加多个标签
- **AND** 标签随文章保存
