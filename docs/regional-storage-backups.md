# 区域排异与加密备份

存储类可设置“排异区域”和“排异文件允许加密备份”。媒体的可见区域减去隐藏区域后，只要与排异区域相交，该存储类就不会保留普通副本。允许加密备份时，对象被压缩和加密后写入私有 `encrypted-backup/v1/<variant>/<uuid>.wbak`；否则跳过该存储类。未指定媒体区域按全球处理。存储类原有 `contentRegions` 不参与此排异判定。

所有副本使用同一媒体 UUID 作为文件名基础。后台每分钟分批检查缺失副本，每五分钟分批读取并校验对象内容；有健康普通副本时自动补齐。只有密文备份存活时，管理员通过“存储同步监控”的恢复操作解密到合规普通存储。普通下载与签名 URL 不读取密文备份。

## 主密码

设置 `WINDBLOG_STORAGE_BACKUP_MASTER_PASSWORD_FILE` 指向仅运行用户可读的文件，或设置 `WINDBLOG_STORAGE_BACKUP_MASTER_PASSWORD`。前者优先。主密码至少 16 个字符，并应足够长且独特。所有参与加密备份的主节点使用同一个密码；密码不会写入数据库或对象存储。每个 `.wbak` 自带解密所需的盐、IV、版本和摘要；仅凭对象及主密码即可离线恢复。密码丢失后无法解密已有备份。

离线恢复时，在仓库根目录运行：

```bash
scripts/decrypt-media-backup.sh <备份文件> <新的输出文件>
```

工具会在终端安全提示输入主密码，并在完整鉴别与校验通过后写出文件；不会覆盖现有输出。对象 UUID 是备份文件名去掉 `.wbak` 的部分。

轮换主密码时，先用 `BackupRekeyTool` 将每个对象转换到新密码并校验；所有对象转换完成前保留旧密码和旧对象。该工具同样可通过上述脚本使用的 classpath 运行，参数为旧备份文件、UUID、新备份文件；它分别提示输入旧密码和新密码。

本地文件系统的密文位于公开上传目录的相邻私有目录。阿里云 OSS 密文对象设置为 private ACL；部署时还须确保 Bucket 策略和 CDN 不对 `encrypted-backup/` 放行。更改区域规则前，应清理可能已缓存旧普通副本的 CDN 内容。
