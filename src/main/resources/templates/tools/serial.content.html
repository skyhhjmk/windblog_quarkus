Web Serial 串口终端

无需安装串口助手或驱动，直接在浏览器内访问 USB/串口设备。所有串口数据在本机浏览器与设备之间传输， 不会上传到服务器。适合调试单片机、路由器、开发板与串口日志。

串口参数

浏览器本地

Web Serial 需要 Chrome / Edge 等 Chromium 浏览器，并在 HTTPS 或 localhost 下打开。

串口权限由浏览器直接授予，数据不会经过 WindBlog 服务器。

未连接
终端会原样显示串口字节流。多数设备使用 115200 8N1；若出现乱码，请检查波特率与校验位。拔掉设备后浏览器会自动断开。
