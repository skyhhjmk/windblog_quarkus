① 选文件 → ② 拿链接配对

可先在下方「选文件」拖拽或加入待传文件（连接建立后自动发送）。

然后在「拿链接」由发起方生成连接码/二维码发给对方；加入方扫码或粘贴后生成应答码传回，发起方确认即可建立 P2P 直连。

防监听加密与 WASM ECC

默认开启 ECDH P-256 + AES-256-GCM 端到端加密，连接后可核对 4 位 Emoji 安全指纹防中间人监听（支持开关切换）。

Reed-Solomon ECC 由隔离的 Rust WASM 驱动，在抗丢包或分片损坏时自动恢复，并配合 SHA-256 校验完整性。

NAT 类型与连接建议

可点击右上角「检测 NAT 类型」判断当前网络：

• 圆锥型 NAT：跨网 P2P 穿透成功率高；

• 对称型 NAT：跨公网直连可能受阻，建议两台设备连入同一 Wi-Fi/热点（切为“仅局域网”），或填写自定义 TURN 中继。
