JSON 格式化与容错修复小贴士

智能容错修复
当 JSON 来自 JS 对象字面量、日志或配置文件时，常伴随单引号、键名未加引号或尾随逗号 (trailing commas)，点击「智能容错修复」即可自动转为标准 RFC 8259 JSON。
快速属性提取
支持以点语法快速提取大型 JSON 嵌套数据，例如 `data.users[0].email`，提取后可直接进行独立查看与复制。
结构化对比模式
对比引擎在比较前自动进行缩进与键名规范化，精准识别对象属性与数组项的变动，排查接口返回差异与配置文件变更极其高效。
