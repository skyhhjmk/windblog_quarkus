常见问题解答 (FAQ)

Q1: 为什么这款图片格式转换器不需要上传文件就能转换？

本工具基于现代浏览器的 HTML5 Canvas API、FileReader 与二进制 ArrayBuffer 构建。当您拖入图片时，您的浏览器直接在本地内存中完成解码与目标格式重编码（包含纯前端实现的 BMP 位图与多尺寸 ICO 容器打包器），全程零网络请求，因此速度极快且绝对保护隐私。

Q2: 透明背景的 PNG 或 WebP 转换成 JPG 时背景变黑怎么办？

由于 JPG/JPEG 格式本身不支持透明通道，许多简易工具直接丢弃 Alpha 通道会导致透明区域变成全黑。本转换器专门内置了「透明背景填充色」合成层，默认为您自动垫上一层纯白背景（#FFFFFF），您也可以自由修改为任意品牌背景色。

Q3: 转换后的图片会自动清除手机拍照的 GPS 定位等 EXIF 信息吗？

是的！当照片通过本地像素画布重编码为新的 PNG、WebP、JPG、AVIF 或 BMP 文件时，原始文件中附带的 EXIF 元数据（包括 GPS 经纬度坐标、拍摄时间、手机/相机型号、快门参数等）会被天然彻底剥离，非常适合在社交平台分享照片前进行隐私脱敏。

Q4: 如何制作高清且兼容所有浏览器的网站 favicon.ico 图标？

点击上方快捷栏的「PNG / SVG 转 ICO (多尺寸 Favicon)」，然后拖入一张正方形的透明 PNG 或 SVG 图标。工具会自动将图像缩放并封装为包含 16×16、32×32、48×48 和 64×64 四个分辨率图层的标准复合 .ico 文件。
