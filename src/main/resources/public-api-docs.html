WindBlog 公共 API

这些接口面向访客或外部调用方。需要用户登录的账户接口、后台接口和内部接口不包含在本目录中。

查看 OpenAPI 3.1 JSON 规范

评论

  • GET /api/comments/post/{slug}：分页读取已发布文章下通过审核的评论。可选参数：page（默认 0）、size（默认 10）。
  • GET /api/comments/quotes/post/{slug}：读取已发布文章下公开的评论引用。

搜索

  • GET /search/suggest?q={query}：根据关键词返回公开文章标题建议；关键词为空时返回空数组。

友链申请

  • POST /api/link-applications：以 JSON 提交友链申请。必填字段为 name、url、email、placementType 和 placementUrl；申请会经过频率限制和站点可达性检查。

公开工具箱 API 与 MCP 端点

  • GET /api/public/tools：获取全部公开网页工具目录及无状态 API 端点。
  • GET /api/public/tools/subnet?cidr=192.168.1.10/24：IPv4/IPv6 子网掩码计算。
  • GET /api/public/tools/timestamp?value=now：Unix 时间戳与 ISO-8601 互转。
  • GET /api/public/tools/cron?expr=*/5%20*%20*%20*%20*&count=5：Cron 表达式未来触发时间推算。
  • POST /api/public/tools/hash：计算 UTF-8 文本的 MD5 / SHA-1 / SHA-256 / SHA-512 哈希值。
  • POST /api/public/tools/token-estimate：估算文本的 LLM Token 数量与字符统计。
  • GET / POST /api/public/mcp：无状态 Model Context Protocol (MCP) JSON-RPC 2.0 端点，供外部 AI Agent 发现并调用上述工具。
