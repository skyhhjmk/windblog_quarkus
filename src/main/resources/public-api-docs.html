WindBlog 公共 API

这些接口面向访客或外部调用方。需要用户登录的账户接口、后台接口和内部接口不包含在本目录中。

查看 OpenAPI 3.1 JSON 规范

评论

  • GET /api/comments/post/{slug}：分页读取已发布文章下通过审核的评论。可选参数：page（默认 0）、size（默认 10）。
  • GET /api/comments/quotes/post/{slug}：读取已发布文章下公开的评论引用。

搜索

  • GET /search/suggest?q={query}：根据关键词返回公开文章标题建议；关键词为空时返回空数组。

友链申请

  • POST /api/link-applications：以 JSON 提交友链申请。必填字段为 name、url、email、placementType 和 placementUrl；申请会经过频率限制和站点可达性检查。
